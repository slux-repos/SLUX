# Slux — Privacy Policy

> **Last Updated:** October 5, 2026

Slux is a Discord bot built to provide useful tools for communities,
including moderation, automation, security, utility, music, and other
server features.

We care about privacy and want this page to be straightforward.

You don't need to understand complicated legal language to know what
happens with your information. This policy explains what Slux can
access, what may be stored, why it may be used, and what you can do
about it.

---

## A quick explanation

The short version is simple:

Slux only needs information that is relevant to the features it
provides.

Depending on how Slux is configured in a server, the bot may process
things such as Discord user IDs, server IDs, channel IDs, roles,
messages, moderation events, and feature settings.

Some information may be stored so that server configuration continues
to work after the bot restarts.

We do not need your Discord password, Discord token, 2FA codes,
recovery codes, or other private login credentials.

We also don't build Slux around selling user information.

That's the basic idea.

The rest of this page explains it properly.

---

## What information can Slux access?

This depends on the permissions given to Slux and the features that
are enabled in a server.

For example, Slux may receive information from Discord such as:

- User ID
- Server ID
- Channel ID
- Role ID
- Message ID
- Voice channel information
- Username or display name
- Server configuration
- Moderation events
- Command usage
- Feature settings

Not every feature uses all of this information.

A music command doesn't need the same information as a moderation
command, and a logging system doesn't need the same information as a
welcome system.

The information available to Slux is therefore largely determined by
what the server has enabled and what Discord makes available to the
bot.

---

## Why does Slux use this information?

Information is generally processed because a feature needs it to
work.

For example, Slux may need information to:

- Execute commands
- Save server settings
- Perform moderation actions
- Keep moderation records
- Run AutoMod
- Detect spam or unwanted activity
- Send configured logs
- Manage tickets
- Manage giveaways
- Operate AutoDM
- Provide music features
- Run utility commands
- Protect the bot from abuse
- Maintain the service

We don't want information simply because it exists.

If a feature doesn't require something, there is normally no reason
for that feature to use it.

---

## Discord account information

Slux works through Discord's API.

When you interact with the bot, Discord can provide the bot with the
information required to respond to that interaction.

This can include your Discord user ID, username, server membership,
roles, permissions, and other information that Discord makes
available through the API.

Slux does not require access to your Discord account credentials.

We will never need:

- Your Discord password
- Your Discord token
- Your 2FA code
- Your recovery codes
- Your private authentication information

If someone asks you for any of these while claiming to be a Slux
developer or support member, do not provide them.

---

## Server configuration

A large part of Slux is based around server configuration.

If an administrator configures a feature, the bot may need to save
that configuration somewhere.

Depending on the features being used, this can include:

- Prefix settings
- Log channels
- Moderation settings
- AutoMod configuration
- Welcome settings
- Ticket settings
- Giveaway configuration
- AutoDM configuration
- Music settings
- Security settings
- Role configuration
- Channel configuration
- Custom command configuration

The reason for storing this information is simple:

If you configure something today, you should not have to configure it
again every time Slux restarts.

---

## Moderation data

Slux includes moderation-related functionality.

When moderation features are used, information connected to a
moderation action may be processed.

For example, a moderation record can involve:

- The user who was moderated
- The moderator who performed the action
- The server
- The channel
- The moderation action
- The reason provided
- Warning information
- Timeout information
- Ban information

The exact information depends on the moderation feature being used.

Moderation information exists to make moderation tools, history,
logging, and related features possible.

---

## AutoMod and security features

Slux may provide automated protection features such as anti-spam,
anti-link, anti-invite, mention protection, caps protection, and
other automated moderation systems.

When these features are enabled, Slux may inspect relevant Discord
events in order to determine whether an automated action should be
taken.

For example, an AutoMod system may need to look at a message to decide
whether it matches a configured spam or link rule.

This processing is tied to the security feature being used.

---

## Messages

Some Slux features may need to process message information.

This can happen when using features such as:

- AutoMod
- Anti-spam
- Custom commands
- Moderation tools
- Message logging
- Certain utility commands

Processing a message does not automatically mean that the message is
stored permanently.

Whether information is stored depends on the feature and the
configuration of the server.

Server administrators should review the logging and moderation
settings they enable.

---

## Custom commands

If a server uses custom commands, Slux may store information required
to make those commands work.

This may include:

- Command name
- Command response
- Server ID
- Permission configuration
- Other command settings

The content created by server administrators through custom command
systems remains the responsibility of the server and its
administrators.

---

## Logging

Slux may provide logging features for server administrators.

Depending on which logs are enabled, a log entry can contain things
such as:

- The event that occurred
- The user involved
- The moderator involved
- The channel involved
- The action performed
- A timestamp
- Relevant message information

Logging is controlled by the server configuration.

If a server administrator enables extensive logging, more event
information may naturally be processed by the bot.

---

## AutoDM

If AutoDM features are enabled, Slux may process information required
to send configured messages to users.

This can include information such as:

- User ID
- Server ID
- AutoDM settings
- Message configuration
- Delivery-related information

AutoDM is controlled by the server administrator.

Slux may provide music and audio-related functionality.

Music features can require information such as:

- The requesting user
- The server
- The voice channel
- Track information
- Queue information
- Playback settings

Depending on how music functionality works, external services may
also receive search or media-related requests.

Those services have their own policies and terms.

Some Slux features may depend on external services.

For example, a feature may use an external provider for:

- Music searches
- Website information
- DNS information
- Blockchain information
- Market information
- Other API-based utilities

When this happens, the information necessary to complete the

You should review the privacy policy of a third-party service if you

## Websites and URL tools

Some utility features may work with websites, URLs, or domain names.

Depending on the feature, Slux may process information such as a URL,
domain name, or publicly available website information.

Examples can include:

- URL utilities
- Website information
- DNS lookups
- Domain information
- Website screenshots

Please don't submit private credentials, passwords, API keys, tokens,
or other confidential information through public utility commands.

This can include:

- Wallet addresses
- Transaction hashes
- Token information
- Network information
- Public blockchain data
- Public market information

- A private key

## Cookies and websites

If Slux operates a website, the website may use cookies or similar

These may be used for normal website functionality, preferences,

The exact use of cookies can depend on the website and the features
available on it.

## How long is information kept?

We don't believe information should be kept forever without a reason.

Information may be retained for as long as it is reasonably needed
for things such as:

- Providing a feature
- Maintaining server configuration
- Security
- Abuse prevention
- Troubleshooting
- Maintaining service reliability
- Handling disputes
- Meeting legal obligations

Different types of information may have different retention periods.

There isn't necessarily one universal retention period for everything
Slux handles.

## Deleting information

Depending on the type of information involved, you may be able to
request that relevant data be removed.

For server configuration, the server owner or authorized
administrator may also be able to remove or reset the relevant
configuration through Slux.

Some information may need to be retained where reasonably necessary
for security, abuse prevention, legal obligations, dispute handling,
or maintaining the integrity of the service.

If you want to make a privacy or deletion request, contact the
official Slux support team.

Server administrators have an important role in privacy.

For example, an administrator may choose to enable:

- Message logging
- Moderation logs
- AutoMod
- AutoDM
- Welcome systems
- Tickets
- Security features
- Other automated features

## Your responsibility

Slux can only control the information handled by its own services.

You should also be careful about what information you share on
Discord or through commands.

Never send sensitive credentials to a bot or support member.

This includes passwords, API keys, Discord tokens, private keys,
seed phrases, recovery codes, and payment credentials.

If something looks suspicious, don't provide it.

## Security

We take reasonable steps to protect information handled by Slux.

However, no internet service can promise that its systems will be
completely secure forever.

Security issues can happen to any online service.

Because of that, we cannot guarantee absolute security.

We still take security seriously and aim to improve the protection
and reliability of Slux as the project develops.

## Do we sell your information?

Slux is not built around selling personal information.

We may use or share information when it is reasonably necessary to
operate a requested feature, use an external provider, protect the
service, prevent abuse, or comply with applicable legal requirements.

We do not intend to turn normal Slux usage into a marketplace for
personal information.

---

## Sharing information

Information may be shared with service providers when doing so is
necessary for the operation of a particular feature.

For example, an external API may receive information required to
complete a request made through one of Slux's utility features.

Information may also be disclosed when reasonably necessary to:

- Protect Slux
- Protect users
- Investigate abuse
- Prevent fraud
- Maintain security
- Comply with legal requirements

We do not share more information than is reasonably necessary for
the relevant purpose where we can avoid doing so.

## Bot permissions

Slux may request Discord permissions that are required for its

## Removing Slux

You can remove Slux from your Discord server at any time.

Once the bot has been removed, it will no longer be able to interact
with that server through Discord in the normal way.

Removing the bot does not necessarily mean every previously stored
piece of information is immediately deleted.

Retention and deletion can depend on the type of information and the
reasons it was retained.
